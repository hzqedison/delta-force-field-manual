Check the machine
before blaming the match.

  • OS Windows 10 64 bit
  • CPU Intel Core i3-4150 / AMD FX-6300

  • GPU GTX 660 / HD 7870 / Intel Arc A380
  • DIRECTX Version 12

  • OS Windows 10 64 bit

  • GPU GTX 1060 5G / RX5500 XT / Intel Arc A580
  • DIRECTX Version 12
  • STORAGE 88 GB available space
PRE-LAUNCH CHECK

Four clean checks.

  1. Update the graphics driver and restart.
  2. Confirm the game has the listed storage headroom.
  3. Test one match on the current network before changing multiple variables.
  4. Record what changed when the issue disappears.
