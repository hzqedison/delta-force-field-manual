01 / FILTER

Set the lane

Pick the mode first. Then use a weapon family, exact name, keyword, or tag such as high stability, recoil control, ranged play, or close-range use.

02 / INSPECT

Read the trade-offs

Open a plan to see its weapon, tags, cost, stats, and attachment list. Treat the card as a starting hypothesis, not a promise that it is best for every patch or player.

03 / COPY

Carry the code

Copy the loadout string after you choose a plan. Keep the code with the build name so you can compare changes when the game or the catalog moves on.

FIELD ROUTINE

Four moves
before deployment.

  1. Choose the mode that matches the match you are about to play.
  2. Filter for a weapon and an intent, rather than browsing every card.
  3. Check the stats and attachments for the trade-off you actually want.
  4. Copy the code, name the build, and test it in the current version.
