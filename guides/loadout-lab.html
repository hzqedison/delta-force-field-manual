FIELD NOTES / 01

Start with the mission,
not the gun.

The tool separates 烽火地带 and 全面战场, then lets you narrow the catalog by weapon type, weapon name, search text, and tags. That is useful because the same rifle can ask for a different compromise when the objective is survival, distance, pressure, or close-range speed.

01 / FILTER

Set the lane

Pick the mode first. Then use a weapon family, exact name, keyword, or tag such as high stability, recoil control, ranged play, or close-range use.

02 / INSPECT

Read the trade-offs

Open a plan to see its weapon, tags, cost, stats, and attachment list. Treat the card as a starting hypothesis, not a promise that it is best for every patch or player.

03 / COPY

Carry the code

Copy the loadout string after you choose a plan. Keep the code with the build name so you can compare changes when the game or the catalog moves on.

WHAT THE CARD HOLDS

One screen
of decisions.

  • STATSDamage, range, recoil control, stability, handling and hip-fire.
  • PARTSAttachment slots, names, images and cost.
  • FILTERSMode, type, weapon name, query and tags.
  • OUTPUTA copyable loadout code for the selected plan.
FIELD ROUTINE

Four moves
before deployment.

  1. Choose the mode that matches the match you are about to play.
  2. Filter for a weapon and an intent, rather than browsing every card.
  3. Check the stats and attachments for the trade-off you actually want.
  4. Copy the code, name the build, and test it in the current version.
EVIDENCE BOUNDARY

A catalog is a compass,
not a patch note.

This guide absorbs the external tool’s structure and observed taxonomy. The full catalog remains on the live source page because plans, costs, stats, images, and codes can change with updates. The source page labels its plan data as an official-HQ collection; this manual does not treat that label as an endorsement of every build.
